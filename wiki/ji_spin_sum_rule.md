# Ji Spin Sum Rule

## Overview
The Ji spin sum rule is proven by manipulating the model expression for H_q(x, 0, 0) + E_q(x, 0, 0) and showing that it equals P_q A_2 Z d3k h t^2 0 + √k^2t^2 1 i. This result is derived from the conservation of the energy-momentum tensor and the derivative of K(⃗ρ).
