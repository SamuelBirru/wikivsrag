# Degenerate States and Mode Number Conservation

## Overview
The paper analyzes the conservation of mode number under the action of ˜Q2 and ˜S2, which leads to the conclusion that intermediate states |χ⟩ should have the same number of magnons as the state |ϕm⟩ they are related to. This constraint significantly reduces the possible contributions from these states.
