# S-Matrix Bootstrap

## Overview
The paper tightens two-sided non-perturbative bounds on the four-dimensional scalar 2-to-2 scattering amplitude using both dual (fixed-t dispersion relation) and primal (crossing-symmetric ansatz) bootstrap methods. It extends the numerical precision of the allowed region in the space of low-energy Wilson coefficients and introduces Regge moments as a new diagnostic tool for extracting emergent high-energy behavior from finite-truncation bootstrap solutions.
