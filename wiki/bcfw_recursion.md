# BCFW Recursion

## Overview
An analytic tool for computing scattering amplitudes in particle physics, which has been extended to gravitational theories using the Null-Infinity-Set-Up (NFS) formulation.

## Papers
- [Ultraviolet-Finite Perturbative Expansion of Quantum Gravity at Null Infinity](http://arxiv.org/abs/2605.06001v1)
