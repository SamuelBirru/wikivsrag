# Gibbs State Generation

## Overview
Gibbs state generation is a process of preparing a quantum system in a specific state, which is essential for studying many-body physics and quantum thermodynamics. In this paper, a quantum generative diffusion model (QGDM) is implemented on a quantum neural network chip to generate Gibbs states.
